## What is this
A wikipedia translation tools with prompt formatting for LLM to improve translation.
Main goal is to make it possible to one shot translation Thai wikipedia page with least effort.
Not currently close but okay I guess

### Feature
- [x] Getting all of the Thai Wikipedia link from English Wikipedia Page
- [x] Convert to markdown and convert back (note: still some bug)
- [x] Decent Prompt (not perfect, but decent yes)
- [] The ability to select specific section to translate
- [x] Can update prompt in the UI
